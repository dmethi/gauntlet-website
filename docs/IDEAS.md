# Ideas

This file incubates possibilities that are not ready to become Studio Linear
work. It is not a backlog, priority list, or commitment.

Promotion follows the shared
[Studio Linear operating model](../../shared-agent-config/portfolio/STUDIO_LINEAR.md).
Projects pull ideas only when they are open for intake. Creating the Linear item
and removing the seed from this file are one transaction.

When the founder commits to an idea, create or attach it to the appropriate
Linear project and remove it here. Durable decisions and constraints belong in
the rest of `docs/`; transient handoff context belongs in `SCRATCHPAD.md`.
